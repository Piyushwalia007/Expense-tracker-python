# Expense Tracker – Python Mini Project

A beginner-friendly Python Expense Tracker mini project that allows users to add, view, and calculate daily expenses using a menu-driven interface.

---

## 📌 Project Objective
The goal of this project is to help users track their daily expenses and understand how real-world data can be handled using basic Python programming concepts.

---

## 🚀 Features
- Add daily expenses (date, category, description, amount)
- View all added expenses
- Calculate total spending
- Menu-driven console interface

---

## 🧠 Concepts Used
- Python Lists
- Python Dictionaries
- Loops (`while`, `for`)
- Conditional Statements (`if-elif-else`)
- f-strings
- User Input Handling

---

## 🛠️ Technologies Used
- Python (Core Python)
